### NBA prop Prediction Engine

Built and interactive machine learning application for estimating NBA player prop over/under probabilities using rolling player performance, matchup context, and game enviornment features.

- Developed rolling player form and minutes trend features
- Engineered opponent defensive and team scoring enviornment metrics using BiqQuery
- Implemented Monte Carlo simulation and recommendation logic
- Built an interactive Streamlit dashboard for player prop exploration

**Tech:** Python, XGBoost, BigQuery, pandas, Streamlit, scikit-learn

[View Project](https://github.com/Thiago-stack/nba-prop-prediction-engine)
